# Pinger - v2.1.0
<br>

## 概要
プレイヤーの視線先にピンを打つ機能を実装するデータパックです。
<br><br>

## 導入手順
1. ワールドのデータパックフォルダにPingerデータパックを配置
2. 旧バージョンのPingerデータパックがある場合は削除
3. ワールド内でPingerデータパックを有効化
<br><br>

## ピン機能の使い方
### 固定ピン
- ブロックにクロスヘアを合わせる ➡ スニーク状態でジャンプ ➡ 滞空中にスニーク１回

### 追従ピン
- エンティティにクロスヘアを合わせる ➡ ノーマル状態でジャンプ ➡ 滞空中にスニーク１回
