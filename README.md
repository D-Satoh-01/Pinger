# Pinger - v2.1.0
<br>

## 概要
プレイヤーの視線先にピンを打つ機能を実装するデータパックです。
<br><br><br>

## 導入手順
**１．ワールドから退出(シングル) or サーバーを停止(マルチ) しておく**<br>
**２．ワールドのdatapacksフォルダを開く**<br>
**３．datapacksフォルダに旧バージョンのPingerデータパックがある場合は削除**<br>
**４．datapacksフォルダにPinger.zipを配置（展開不要）**<br>
**５．ワールドに入る or サーバー起動**<br>
**６．ワールド内で初回歩行時にテキストメッセージが表示されれば導入完了**<br>

上記手順で導入できないときは以下の手順を試してください。

**１~４．上と同じ**<br>
**５．ワールド内でコマンド⠀/datapack enable "file/Pinger.zip"⠀を実行**<br>
**６．ワールド内でコマンド⠀/reload⠀を実行（もしくはワールド再入室 or サーバー再起動）**<br>
**７．ワールド内で初回歩行時にテキストメッセージが表示されれば導入完了**<br>

それでも導入できないときは状況･環境に応じて試行錯誤してみてください。（zipファイルを展開して配置してみるなど）
<br><br><br>

## ピン機能の使い方
### 固定ピン
- クロスヘアをブロックに合わせる ➡ スニーク状態でジャンプ ➡ 滞空中にスニーク１回

### 追従ピン
- クロスヘアをエンティティに合わせる ➡ ノーマル状態でジャンプ ➡ 滞空中にスニーク１回
