# Pinger - v2.1.0
<br>

## 概要
プレイヤーの視線先にピンを打つ機能を実装するデータパックです。
<br><br>

## 導入手順
1. ワールドのdatapacksフォルダにPingerデータパックを配置（展開不要）
2. 旧バージョンのPingerデータパックがある場合は削除
3. ワールド内でコマンド⠀/datapack enable "file/Pinger.zip"⠀を実行
4. ワールド内でコマンド⠀/reload⠀を実行（もしくはワールド再入室 or サーバー再起動）
5. ワールド内で初回歩行時にテキストメッセージが表示されれば導入完了
<br><br>

## ピン機能の使い方
### 固定ピン
- クロスヘアをブロックに合わせる ➡ スニーク状態でジャンプ ➡ 滞空中にスニーク１回

### 追従ピン
- クロスヘアをエンティティに合わせる ➡ ノーマル状態でジャンプ ➡ 滞空中にスニーク１回
